# TCP 멀티플레이 게임 서버

> 2018년 대학 팀 프로젝트  
> 3인 개발 / 게임 서버 개발 담당

TCP/IP 소켓 프로그래밍을 기반으로 2인 파티 플레이를 지원하는
멀티플레이 게임 서버를 구현한 프로젝트입니다.

## 프로젝트 개요

- 개발 기간: 2018.10.31 ~ 2018.12.10
- 개발 인원: 3명
- 개발 환경: Visual Studio 2017
- 언어: C/C++
- 통신 방식: TCP/IP

## 담당 업무

게임 서버의 메인 프레임워크와 네트워크 처리를 담당했습니다.

- TCP/IP 소켓 프로그래밍을 이용한 네트워크 환경 구축
- 게임 서버 메인 프레임워크 구현
- `std::vector`를 이용한 접속 플레이어 관리
- 멀티스레드를 이용한 `recv` / Main Loop 분리
- `mutex`를 이용한 공유 데이터의 Data Race 방지
- 플레이어 접속 및 이동 동기화
- 키 입력 및 애니메이션 동기화
- 스킬 및 이펙트 동기화
- 클라이언트 매칭 및 2인 파티 플레이 구현
